# DEAFCS map images

Map posters and patches for deafcs.net, served through jsDelivr so they can be
set in the panel (Settings > Application > Map Pools) without a web deploy.

- Poster: `https://cdn.jsdelivr.net/gh/DEAFCS/map-images@main/screenshots/<map>.webp`
- Patch: `https://cdn.jsdelivr.net/gh/DEAFCS/map-images@main/icons/<map>.svg`

Upload a file to `screenshots/` or `icons/`, named after the map (for example
`de_cbble`). A changed file can take up to 12 hours to show through jsDelivr's
cache; a new file name shows at once.

`de_cbble` comes from CS2 itself: the 1080p map screenshot and the map icon
from `pak01_dir.vpk` (panorama/images/map_icons).
